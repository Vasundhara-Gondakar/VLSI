
# Standard Cell Layout Design – UMC 180 nm

Designed and implemented standard cell layouts using **Cadence Virtuoso** and **UMC 180 nm CMOS technology**.

### Cells Designed
- AOI21 
- OAI31
- 2:1 Multiplexer (MUX) 
- Inverter
- AND Gate

### Tools & Technology
- **EDA Tool:** Cadence Virtuoso
- **Technology:** UMC 180 nm CMOS
